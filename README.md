# ClearUI

ClearUI is a modern React-based repository of reusable UI component examples.

## Included component demos

- Button variants (primary, secondary, outline)
- Modal interactions
- Card + alert states (success and warning)
- Data table layout
- Input fields
- Search bar
- Combined page examples:
  - Dashboard
  - Login

## Layout

- Left sidebar navigation (~12% of screen width) with full-width button links.
- Main content area that swaps between component demos.

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm test`
Runs the test suite.

### `npm run build`
Builds the app for production.
